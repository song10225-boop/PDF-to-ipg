PDF 도구

PDF를 이미지로 변환

PDF의 각 페이지를 JPG 또는 PNG 파일로 저장합니다.

이미지를 하나의 PDF로

여러 이미지를 추가한 뒤 드래그해 순서를 바꿀 수 있습니다.

PDF 파일 병합

여러 PDF를 한 파일로 합칩니다. 목록을 드래그해 순서를 바꾸세요.

PDF 페이지 편집

페이지를 미리 보고 삭제하거나 드래그해 순서를 바꾸세요.

PDF 페이지 분할

페이지 범위를 입력해 여러 PDF로 나누고 ZIP 파일로 다운로드합니다.

쉼표로 구분하세요. 예: 1-3, 4-6, 7-10. 범위마다 별도 PDF가 생성됩니다.

파일 처리는 브라우저에서 진행됩니다.
